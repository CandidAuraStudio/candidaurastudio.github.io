# HeartClear master hub — integration plan (not a live HeartClear edit)

## Goal
Keep **HeartClear** the master experience for meditation, sounds, audiobooks, Human Practice and daily life. Add an optional small **Explore More** section only after the user tests NIYYAH and approves the placement.

| Destination | App | Proposed link |
|---|---|---|
| Intention, ego, Qur'anic reflection | NIYYAH | https://candidaurastudio.github.io/niyyah/ |
| Cultural heritage, forgotten foods, human voices | HUMAN ATLAS | https://candidaurastudio.github.io/human-atlas/ |
| Private personal recordings and reflections | INNER VOICE | https://candidaurastudio.github.io/inner-voice/ |
| Screenplay, shot planning and storyboards | STORY ENGINE | https://candidaurastudio.github.io/story-engine/ |

## Interaction and preservation rules
- Simple optional links, never cross-app storage reads, data merges, copied journals or user identification.
- Preserve HeartClear's current dark floating interface, meditation/audio/video player, resume, offline, Sound Lab, Sacred Sound, audiobooks, history and all working features.
- Links should explain that the destination is a separate app, and offer a return to HeartClear.
- Cooking traditions and traditional food preservation belong primarily to HUMAN ATLAS; HeartClear may show a small curated entry card if user requests it.
- TikTok/reels/story video production may later link from HeartClear to STORY ENGINE. Do not add uploads or autoplay video until the user supplies content/permissions.
- Check Android, iOS and installed-PWA link behavior; use safe external navigation with explicit target only when necessary.
- No publishing this navigation change without review of latest HeartClear files and user testing.

## Current status
Plan prepared; **HeartClear unchanged**. NIYYAH is separate and functional, but its deeper Baqarah commentary and per-verse Juz Amma translations remain works in progress.
