# Human Atlas Prototype 01

Independent mobile-first prototype for cultural memories and human stories.

Site: https://candidaurastudio.github.io/human-atlas/

Everything is scoped to this folder. Nothing under human-practice-prototype or HeartClear was modified for this release.

Prototype includes six collections, twelve clearly labeled editorial examples, searchable archive, native speech synthesis, bookmarks, and private notes with JSON export/import.

Local notes and photos stay in this browser's storage; they are not synced or backed up automatically. Export a copy if you need to keep them. Real stories should be added only after factual review and consent.

No paid AI or third-party libraries. index.html is a self-contained deployment artifact; the PWA manifest, worker and SVG icon support standalone/offline use in compatible browsers.
