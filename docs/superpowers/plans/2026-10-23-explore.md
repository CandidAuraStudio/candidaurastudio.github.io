# HeartClear Explore Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement inline.

**Goal:** Add a small Home Explore entry with a guessing game and private symptom organiser, both with tap and optional confirmed voice input.

**Architecture:** A pure CommonJS/browser core contains game selection, answer parsing and health routing. A separate browser module renders a native dialog and manages the microphone lifecycle. Existing index and service worker load/cache the small files.

**Tech Stack:** Vanilla JavaScript, CSS, browser Web Speech, Node test runner, Playwright.

**Spec:** ../specs/2026-10-23-explore-design.md

## Global Constraints
- No paid API or credentials; no remote AI.
- No diagnostic, treatment or guaranteed accuracy claims.
- Health answers stay in memory; microphone requires disclosure and confirmation.
- Preserve existing media and navigation.

## Review Focus
- Unknown and contradictory game answers must not cause certain guesses.
- Unsure on safety questions must never produce an all-clear.
- Late voice callbacks after closing must not record answers.
- Permission denial and unsupported recognition must leave tap usable.
- Cached scripts and Home integration must match the published revision.
